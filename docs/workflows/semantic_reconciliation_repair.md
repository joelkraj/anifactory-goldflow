# Exact semantic reconciliation corrections

After a failed global reconciliation, retain its immutable failed checkpoint and inspect the actual source and findings. A source-bound `goldflow_semantic_reconciliation_repair_v1` may repair exact evidence excerpts or scene anchors, or append missing cited actor identities under the existing contract. Use the status-emitted `--semantic-chunk-ids global_reconciliation` command with `--manual-reconciliation-evidence <reviewed-json>`. Passed extraction packets stay unchanged; this route makes no new planner call.

An exact `ref_requirement_kind` operation may correct one scene reference's schema classification. It binds `collection: scenes`, `row_index`, `row_id`, `ref_index`, `ref_id`, and `expected_kind`, and supplies a reviewed `replacement_kind` (`location`, `character_state`, `prop`, `ui`, or `action`) plus a substantive `review_note`. The editor decides whether the source depicts an actor, apparatus, effect, or another supported reference role. No keyword mapping makes that decision. All other reference fields and scene content remain unchanged.

The repair binds the current source hash, failed checkpoint file hash, and original prompt hash. Ordinary evidence, scene coverage, actor coverage, and reference-kind validation still run; a correction cannot waive them or change the approved narration. Re-read status after import.
