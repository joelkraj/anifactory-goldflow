# CrimeDungeon: a recurring style system

September 9, 2026. Response to the user's requirement for a concrete, repeatable format that does not depend on repeated coaching.

The controlling artifact is the [house style](../../docs/designs/crimedungeon_style_bible_v1.md). It records the reference-supported scene grammar, seven visual modes, authored typography/color/motion presets, three sound states, opening variants, question/payoff structure, conclusion and comparison criteria. [AGENTS.md](../../AGENTS.md) now routes all new true-crime development through it.
