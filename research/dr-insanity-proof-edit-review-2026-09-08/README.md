September 8, 2026. This is an audiovisual reference comparison and a proposed next edit of the retained **64.4-second** private proof. No proof script, narration, media, identity or production code was changed by this study.

## The main editorial finding

Removing the long reading holds fixed the obvious silence problem. The next weakness is the visual and audio range: most of our proof uses the same dark board, cream cards, several competing text layers and one continuous narrator. The references change presentation as the investigation changes: a person speaks, narration supplies context, a record or map tests the account, then a new encounter develops it. Our existing documents and cutouts can support this same progression if each visual change has an informational purpose.

The next pass should prioritize **readable focal points, progressive evidence reveals, distinct scene treatments and restrained sound**, while keeping the tighter duration. It should not remove more time merely to increase apparent speed.

## Implementation order

1. **Picture hierarchy and reveal timing:** revise layouts, progressive crops/highlights and continuity using existing assets. This produces the largest immediate gain without new narration or case material.
2. **One restrained sound pass:** choose the actual owned/licensed bed and a very small number of editorial accents, retain their provenance, and mix against this exact narration. Review on speakers/headphones and at a phone-sized picture. No new audio asset has been selected in this study.
3. **A meaningful original-audio passage when available:** a checked interview, testimony or search excerpt can introduce a second sound perspective and a real event for the narrator to explain. Its date and source must be explicit. It is an additional creative option, not a mandatory footage quota or a reason to stop improving the document/cutout treatment.

For the eventual longer format, use an editorial beat list with five fields: **viewer question, source moment, what changes, picture cue, sound cue**. Log several representative windows from each reference using those same fields. Separate source-exchange duration from individual shot duration and promotional material from story pacing. Judge our revisions on comprehension, reveal timing, intelligibility and momentum; the references' popularity does not establish which single technique caused their performance.
